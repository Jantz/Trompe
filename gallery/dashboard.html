Material world

Meridian is the operations dashboard of an invented bike-courier company, built as an instrument panel: a graphite anodised plate under a brushed aluminium header, every module a raised plate with a diamond-cut chamfer, every display set behind a mitred chrome bezel and cover glass. Each display is a different technology and lights itself, independent of the scene light: an amber VFD with ghost segments, filament wires and a grid mesh for the KPIs, an LED bar-graph ladder for service level, a mint OLED with a pixel grid for the hourly chart, a backlit analog gauge with a sprung needle, and a reflective e-paper panel for the route table that flashes when it redraws.

Everything is CSS gradients, shadows and a little SVG. Bevels, chamfers, the brushed highlight, glass reflections and every cast shadow read the shared light, so turning the light dial re-lights the panel. All figures are sample data computed from one seeded model, so range, region and live updates stay consistent across displays.

Controls: illuminated latching nav keys (← →), a smoked-glass range listbox (↑ ↓ Home End Enter Esc, type to jump), a four-detent rotary region selector, a guarded bat-handle Live toggle, a recessed glass search well, a domed refresh key, an SLA fader, illuminated soft-keys beside the e-paper rows with bulk actions, an alert lamp with Dismiss, and an aluminium export dialog with jewel-lamp radios.
